

# Farbe

A typesafe interface for rendering over OpenGL ES 2 and GLFW. It comes with an eDSL for writing shaders and simple combinators for rendering.

[haddock docs](https://vekkq.github.io/farbe/dist-newstyle/build/x86_64-windows/ghc-9.12.1/farbe-0.1.0.0/doc/html/farbe/Graphics-Farbe.html).


## work in progress

Code optimization is currently not implemented and will produce huge chunks of redundant shader code.

The error texture is a mess when made after a first time, for no clear reason.

A few additional functions on stencils are mostly untested. 

Bigger projects were never tried.
